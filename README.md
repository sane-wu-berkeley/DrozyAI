# DrozyAI

For live Forerunner 970 sensor data in a MacBook Python terminal, use the
[Garmin sensor companion setup](server/README.md). It extends the existing watch
app and uses Garmin Connect Mobile plus HTTPS, with raw CSV recording and Python
RMSSD. The separate [iPhone companion](phone-companion/README.md) remains the
camera/model/phone-alert relay.
The pitching video is now online: https://youtu.be/_8VhdZ8NhKs
